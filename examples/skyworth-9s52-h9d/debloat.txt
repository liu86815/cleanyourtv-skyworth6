# ROM restrictions discovered on this device (important before reusing this list):
# - `pm disable-user` / `pm disable-until-used` / `pm hide` all throw SecurityException from shell (uid 2000):
#   the Coocaa PMS blocks shell from changing component state, regardless of the target package's uid.
# - `adb root` refuses ("adbd cannot run as root in production builds") despite the userdebug build string.
# - `pm block` and `pm install-existing` do not exist on this build.
# - WORKING method: `pm uninstall -k --user 0 <pkg>` (keeps data, system partition untouched).
#   Restore: `pm install -r --user 0 <system apk path>` (verified working on this device).
#
